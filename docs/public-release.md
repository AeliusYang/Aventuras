# 独立公开源码副本

## 默认提示词

内置默认包名为“中文写作”，不包含当前 Director、当前 Writer 和旧版 Writer 的成人场景专节。保留自然语言输入解释、主角决定权、开放停点、叙述距离、反复表达约束与用户指定篇幅。

Director、Writer、长期规划、模式分析和剧情建议五个模板均接收故事设置的 `themes` 变量。可在[默认提示词全文](default-prompts.md)查看六个中文写作 Agent 的实际内容。

默认注册表包含 54 个模板，覆盖中文写作、普通冒险及共用服务；不包含已停用的中文写作行动菜单，也不预置个人自定义变量或运行时变量。

默认模板定义位于 `src/lib/services/prompts/templates/public-defaults.json`。现有 Pack 初始化、普通创建和角色卡导入都通过统一注册表取得这些内容。Prompt Inspector 的来源标注为“中文写作（内置默认）”，不附带私人预设的原文摘录或清单。

本次清理删除成人专用指导，不增加生成后的内容审查或文学返工阶段，也不宣称能保证所有模型输出适合所有年龄。一般情感、人物关系、身体感受与心理描写仍保留。导入器里“忽略 NSFW 开关”等防止角色卡指令混入的规则不是成人创作指导，继续保留。

## 发布范围

保留现有应用代码、必要构建文件、通用图标、单元测试、架构文档及许可证。排除数据库、连接配置、故事与角色卡导出、备份、开发归档、个人评测报告、实时 API 评测、私人预设清单及其提取脚本。不包含 `.git` 历史、依赖目录和编译产物。

原来的真实生成样本不随源码发布；相应回归测试采用人工构造的最小样本。上游自动发布工作流和向上游推送的发布脚本不随副本发布。该目录尚未创建提交或设置远程仓库。
